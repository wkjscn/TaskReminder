关于本系统

一个由AI完全开发的轻量级事项提醒管理系统，支持按间隔天数自动发送提醒通知到 Telegram、邮箱、飞书、Bark。

功能特性
  • 提醒管理：创建/编辑/删除/启停/克隆
  • 定时发送：可按间分，时，天，月间隔自动发送
  • 多渠道：Telegram / 邮件 / 飞书 /Bark
  • 支持独立配置通知渠道
  • 支持多用户登录使用系统
  • 响应式设计，支持移动端

新建事项提醒

通知渠道配置
📖 配置说明
在 Telegram 搜索 @BotFather，发送 /newbot 创建机器人，获取 Bot Token。然后搜索 @userinfobot 发送任意消息，获取 Chat ID。
📖 配置说明
使用邮箱服务商提供的 SMTP 服务。Gmail 需要开启应用专用密码；QQ邮箱/163邮箱等需获取授权码。
📖 配置说明
1.在 开放平台 创建飞书应用，获取 App ID 和 App Secret。应用需开启「机器人」能力
2.在「事件与回调 → 事件配置」中选择「使用长连接接收事件」
3.在权限管理中添加 im:message:send_as_bot（以应用身份发消息）权限。
4.接收者 ID 为用户的 open_id，可在通讯录或通过 OpenAPI 获取。
📖 配置说明
Bark 是 iOS 平台的通知推送工具，需在 iPhone 上安装 Bark App 获取推送 URL。支持两种格式：
1. 完整 URL: https://api.day.app/{device_key}
2. 仅key: abc123
